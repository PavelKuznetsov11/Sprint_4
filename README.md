
# Unit Testing - BooksCollector (Pytest)

Проект реализует unit-тестирование бизнес-логики приложения BooksCollector.

## 📌 Описание

Проект по разработке unit-тестов для приложения BooksCollector.  
Тестируется бизнес-логика работы с книгами: добавление, управление жанрами, фильтрация и работа с избранным.

---

## 🎯 Цель

Обеспечить корректную работу основных методов приложения и проверить обработку граничных и негативных сценариев.

---

## 🔍 Проверяемые сценарии

- Добавление книги
- Установка жанра
- Фильтрация по жанру
- Работа с избранным

---


## 🧪 Что было протестировано

### 📚 Работа с книгами

- Добавление новых книг
- Проверка ограничений на длину имени
- Запрет на добавление дубликатов

### 🏷 Управление жанрами

- Установка жанра для существующей книги
- Обработка попытки установки жанра для несуществующей книги
- Проверка недопустимых жанров
- Получение жанра книги

### 🔍 Фильтрация книг

- Получение списка книг по заданному жанру
- Обработка случаев отсутствия данных
- Проверка пустых результатов

### 👶 Книги для детей

- Фильтрация книг по допустимым жанрам
- Исключение недопустимых жанров

### ⭐ Избранное

- Добавление книги в список избранного
- Проверка на дубликаты
- Удаление книги из избранного
- Получение списка избранных книг

---

## 🛠 Используемые технологии

- Python
- Pytest

---

## 📊 Результат

- Покрыты основные сценарии работы приложения  
- Проверены граничные значения и негативные кейсы  
- Достигнуто 100% покрытие кода тестами
