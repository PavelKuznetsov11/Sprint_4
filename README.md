# Books Collector Unit Tests

Проект с unit-тестами для проверки бизнес-логики приложения Books Collector.

Цель проекта — проверить работу методов приложения на уровне unit-тестов: добавление книг, работа с жанрами, избранное и обработка ограничений.

## Что тестируется

- добавление книг
- добавление книг с некорректными данными
- установка жанра книги
- получение жанра книги
- получение книг по жанру
- добавление книг в избранное
- удаление книг из избранного
- проверка ограничений по названию книги
- негативные и граничные сценарии

## Технологии

- Python
- Pytest
- Unit testing
- Git

## Что проверяют тесты

- корректность работы методов
- позитивные сценарии
- негативные сценарии
- граничные значения
- обработку некорректных данных
- работу с коллекциями данных

```text

├── README.md           # описание проекта

Как запустить проект

Клонировать репозиторий:
git clone https://github.com/PavelKuznetsov11/books-collector-unit-tests.git

Перейти в папку проекта:
cd books-collector-unit-tests

Создать и активировать виртуальное окружение:
python -m venv venv

Для Windows:
venv\Scripts\activate

Для macOS / Linux:
source venv/bin/activate

Установить зависимости:
pip install -r requirements.txt

Запустить тесты:
pytest -v

Примеры проверок:
книга успешно добавляется в коллекцию
книга с пустым названием не добавляется
книга с названием больше допустимой длины не добавляется
книге можно установить жанр
книгу можно добавить в избранное
книгу можно удалить из избранного
метод возвращает книги с определённым жанром

Результат:
В проекте реализованы unit-тесты на Pytest для проверки бизнес-логики приложения.
Тесты покрывают позитивные, негативные и граничные сценарии.
